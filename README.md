# Simple CLI Task Tracker

A lightweight Command Line Interface (CLI) To-Do List application built with Python.

---

## 🌟 Features
- View all current tasks with sequential numbering.
- Add new tasks dynamically.
- Delete existing tasks by their index.
- Input validation and error handling for user interactions.

---

## 🛠️ Tech Stack
- **Language:** Python 3
- **Environment:** Linux / Fedora Silverblue
